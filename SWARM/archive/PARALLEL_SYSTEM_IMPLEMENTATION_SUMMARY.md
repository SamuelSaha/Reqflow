## 🚀 USAGE

### Start a Parallel Sprint

```bash
# 1. Decompose feature into workstreams
*parallel decompose "Build user dashboard"

# 2. Execute all workstreams simultaneously
*parallel execute

# 3. Synchronize and merge results
*parallel sync

# 4. Verify and ship
*parallel verify
```

### Use MoA for Complex Decisions

```bash
# Spawn 3 proposers + 1 aggregator
@moa spawn --task "design-api" --agents arch,dev,sec

# Aggregate best elements
@moa aggregate
```

### Optimize Tokens

```bash
# Load only relevant skills
@swarm-dev Use token-optimization skill

# Follow 2k token rule per agent
# Compress outputs to bullets
# Prune completed phases
```
